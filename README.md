# RadioBot

![RadioBot — радиоэфир и любимая музыка](assets/radiobot-readme.png)

Telegram-бот, который показывает текущую музыку на популярных радиостанциях и уведомляет, когда в эфире появляется песня из любимых треков пользователя в Spotify.

## Что умеет бот

- показывает текущую песню на выбранной радиостанции;
- собирает сводку по всем станциям одной кнопкой;
- обновляет сведения об эфире без повторного ввода команд;
- подключается к личному аккаунту Spotify;
- подключается к Яндекс Музыке по одноразовому коду без передачи пароля;
- выводит 10 последних добавленных любимых треков;
- сравнивает эфир со всей библиотекой «Любимых треков»;
- присылает уведомление, если любимая песня играет на радио;
- показывает 10 последних треков каждой станции;
- позволяет выбрать избранные станции и источники уведомлений;
- поддерживает тихие часы и ежедневные итоги в 20:00 по Москве;
- добавляет ссылки для поиска трека в Spotify, Яндекс Музыке и YouTube;
- сохраняет текущий трек в Spotify или Яндекс Музыку одной кнопкой;
- показывает статистику эфира и экспортирует историю в CSV;
- ежедневно создаёт резервную копию SQLite и хранит последние семь копий;
- поддерживает фильтр уведомлений по исполнителю и паузу между повторами;
- записывает историю эфира в отдельный журнал.

Поддерживаются 11 станций:

1. Максимум
2. Лайк ФМ
3. Камеди Радио
4. Энерджи
5. Лав Радио
6. Европа Плюс
7. ДФМ
8. Рекорд
9. Кисс ФМ
10. Хит FM
11. Монте Карло

## Как пользоваться

После первого запуска откройте чат с ботом и нажмите **«📻 Старт»**. В нижней части чата появится постоянная клавиатура.

### Узнать текущую песню

Нажмите кнопку нужной радиостанции. Бот запросит свежие данные и покажет исполнителя, название композиции и время проверки.

Кнопка **«🔄 Обновить»** повторно проверяет ту же станцию, а **«📻 Другие станции»** возвращает к списку.

### Получить общую сводку

Нажмите **«📋 Все станции»** или кнопку **«📋 Сводка по всем»**. Бот параллельно проверит все 11 станций и соберёт результаты в одном сообщении.

### Подключить Spotify

1. Нажмите **«🟢 Подключить Spotify»**.
2. Перейдите по ссылке, войдите в Spotify и разрешите чтение любимых треков.
3. Если после подтверждения открылась недоступная страница `127.0.0.1`, скопируйте полный адрес из строки браузера и отправьте его боту.
4. Бот завершит подключение и удалит сообщение с одноразовым кодом.

Авторизация сохраняется между перезапусками. Когда временный токен истекает, бот обновляет его автоматически.

### Посмотреть последние лайки

Кнопки **«💚 Лайки Spotify»** и **«💛 Лайки Яндекс»** показывают 10 композиций,
которые пользователь добавил в любимые последними.

### Подключить Яндекс Музыку

1. Нажмите **«🟡 Подключить Яндекс Музыку»**.
2. Откройте официальный адрес Яндекса из сообщения.
3. Введите показанный ботом одноразовый код и подтвердите доступ.

Бот не получает пароль. Для чтения «Мне нравится» используется неофициальная
библиотека API Яндекс Музыки, потому что публичного официального API этой
функции нет. Полученный токен хранится в постоянной SQLite-базе.

### Получать уведомления

Бот раз в минуту проверяет эфир всех станций и сравнивает композиции со всей
библиотекой любимых треков Spotify и Яндекс Музыки, а не только с последними
десятью.

Полная библиотека Spotify синхронизируется не чаще одного раза в сутки по
московскому времени и сохраняется в SQLite. Проверка эфира и кнопка последних
лайков используют локальный кеш. Если Spotify временно недоступен, бот продолжает
работать с результатом последней успешной синхронизации и повторяет попытку на
следующий день. Для сравнения бот:

- игнорирует регистр, лишние пробелы и знаки препинания;
- одинаково обрабатывает `ё/е` и `&/and`;
- убирает пометки `Radio Edit`, `Remix`, `Remastered` и похожие;
- допускает небольшие опечатки с помощью строгого нечёткого сравнения;
- не использует нечёткое сравнение для слишком коротких названий, чтобы избежать ложных совпадений.

Одно и то же совпадение не отправляется повторно при каждой проверке. История уведомлений сохраняется после перезапуска.

### История, избранное и уведомления

В карточке станции доступны кнопки **«Последние 10»** и **«В избранное»**.
Кнопка **«⭐ Мои станции»** открывает сокращённый список выбранных станций.

В разделе **«⚙️ Уведомления»** можно оставить только нужные станции и включить
тихие часы. Совпадения, обнаруженные во время тишины, попадут в итоги дня без
отдельного ночного сообщения. Кнопка **«📊 Итоги дня»** показывает совпадения
вручную, а автоматическая сводка отправляется в 20:00 по московскому времени.

Владелец может узнать свой Telegram ID командой `/id`, добавить его в переменную
`ADMIN_USER_ID` и проверять состояние источников командой `/admin_sources`.

Администратору также доступны `/admin`, `/backup`, `/sync_now`. Пользовательские
команды `/stats`, `/export`, `/sync`, `/rules`, `/watch`, `/unwatch`, `/cooldown`
показывают статистику, выгружают CSV и управляют персональными уведомлениями.
Текущая версия доступна через `/version` и публичный `/health`.

Бот автоматически проверяет все станции раз в минуту. После трёх неудачных
проверок подряд администратор получает сообщение о недоступном источнике. Если
трек не меняется 30 минут, бот предупреждает о возможном зависании. После
восстановления приходит отдельное уведомление. Пороговые значения можно изменить
через `SOURCE_FAILURE_THRESHOLD` и `SOURCE_STALE_MINUTES`.

## Откуда берутся данные

Для станций используются разные источники: официальные страницы, JSON-метаданные, HLS-метаданные и ICY-данные эфирных потоков. Если основной источник станции временно недоступен, бот пытается получить название из альтернативного потока.

Такой подход нужен потому, что единого надёжного каталога текущих песен для всех радиостанций не существует.

## Журнал эфира

История композиций записывается в `logs/airplay.log` в кодировке UTF-8:

```text
2026-08-07 19:31:11 Европа Плюс — The Second Voice - LET ME BE
2026-08-07 19:31:11 Энерджи — Alok & Sigala feat. Ellie Goulding - All By Myself
```

Новый трек записывается сразу. Одинаковая композиция одной станции не дублируется чаще одного раза за три минуты. Файл ограничен 5 МБ, после чего создаются архивные копии.

Рабочие логи контейнера выводятся в удобном формате с московским временем:

```text
09.11.2026 18:30:00 | INFO    | src.bot                | BOT READY | @example_bot | id=123
09.11.2026 18:31:04 | INFO    | src.bot                | RADIO CHECK | stations=10/11 | users=2 | matches=1 | sent=1 | 4.2s
09.11.2026 18:31:04 | WARNING | src.bot                | RADIO NO DATA | dfm
```

Токены, пароли и другие секреты в журнал не записываются.

## Минимальный запуск

Требуется Python 3.11 или новее.

```powershell
python -m venv .venv
.venv\Scripts\pip.exe install -r requirements.txt
Copy-Item .env.example .env
.venv\Scripts\python.exe -m src.bot
```

Перед запуском заполните `BOT_TOKEN` и настройки Spotify в `.env`. Файл `.env`, база `data/spotify.sqlite3` и папка `logs/` исключены из Git.

Проверка проекта:

```powershell
.venv\Scripts\python.exe -m unittest discover -s tests -v
.venv\Scripts\ruff.exe format .
.venv\Scripts\ruff.exe check .
```

## Размещение на Railway

Проект готов к запуску из Docker-контейнера. После публикации компьютер можно
выключать: бот будет работать на сервере Railway.

1. Создайте в Railway проект из этого GitHub-репозитория.
2. Добавьте к сервису Volume и смонтируйте его в `/app/storage`.
3. Добавьте переменные окружения:

   ```text
   BOT_TOKEN=...
   SPOTIFY_CLIENT_ID=...
   SPOTIFY_CLIENT_SECRET=...
   SPOTIFY_REDIRECT_URI=https://<домен-railway>/spotify/callback
   DATABASE_PATH=/app/storage/spotify.sqlite3
   LOG_DIR=/app/storage/logs
   ADMIN_USER_ID=<ваш Telegram ID>
   SOURCE_FAILURE_THRESHOLD=3
   SOURCE_STALE_MINUTES=30
   ```

4. В разделе Networking создайте публичный домен Railway.
5. В настройках приложения Spotify добавьте тот же адрес
   `https://<домен-railway>/spotify/callback` в список Redirect URIs.
6. Перезапустите Deployment после сохранения переменных.

Railway сам задаёт `PORT`, проверяет `/health` и перезапускает процесс после
сбоя. Токен Telegram и секрет Spotify нельзя записывать в репозиторий.
