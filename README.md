# RadioBot

Telegram-бот с кнопками популярных российских радиостанций. По нажатию бот находит рабочий эфирный поток через Radio Browser и читает из него ICY-метаданные текущей композиции.

В списке 11 станций: «Максимум», «Лайк ФМ», «Камеди Радио», «Энерджи», «Лав Радио», «Европа Плюс», «ДФМ», «Рекорд», «Кисс ФМ», «Хит FM» и «Монте Карло». Станции разбиты на страницы по восемь кнопок.

## Запуск

1. Создайте бота у [@BotFather](https://t.me/BotFather) и получите токен.
2. Установите Python 3.11 или новее.
3. Выполните в папке проекта:

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
Copy-Item .env.example .env
```

4. В `.env` замените пример на настоящий токен и запустите:

```powershell
python bot.py
```

В Telegram отправьте боту `/start`, затем нажмите кнопку станции. Кнопка «Обновить» повторно проверяет эфир.

## Ограничение

Название песни доступно только тогда, когда сама станция передаёт его в ICY-метаданных потока. Если таких данных нет, бот покажет понятное сообщение вместо выдуманного результата.

## Проверка

```powershell
python -m unittest -v
```

Для разработки установите Ruff и запускайте форматирование и линтинг после изменений:

```powershell
pip install -r requirements-dev.txt
ruff format .
ruff check .
```
