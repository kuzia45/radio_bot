# RadioBot

![RadioBot — радиоэфир и любимая музыка](assets/radiobot-readme.png)

Telegram-бот, который показывает текущую музыку на популярных радиостанциях и уведомляет, когда в эфире появляется песня из любимых треков пользователя в Spotify.

## Что умеет бот

- показывает текущую песню на выбранной радиостанции;
- собирает сводку по всем станциям одной кнопкой;
- обновляет сведения об эфире без повторного ввода команд;
- подключается к личному аккаунту Spotify;
- выводит 10 последних добавленных любимых треков;
- сравнивает эфир со всей библиотекой «Любимых треков»;
- присылает уведомление, если любимая песня играет на радио;
- записывает историю эфира в отдельный журнал.

Поддерживаются 11 станций:

1. Максимум
2. Лайк ФМ
3. Камеди Радио
4. Энерджи
5. Лав Радио
6. Европа Плюс
7. ДФМ
8. Рекорд
9. Кисс ФМ
10. Хит FM
11. Монте Карло

## Как пользоваться

После первого запуска откройте чат с ботом и нажмите **«📻 Старт»**. В нижней части чата появится постоянная клавиатура.

### Узнать текущую песню

Нажмите кнопку нужной радиостанции. Бот запросит свежие данные и покажет исполнителя, название композиции и время проверки.

Кнопка **«🔄 Обновить»** повторно проверяет ту же станцию, а **«📻 Другие станции»** возвращает к списку.

### Получить общую сводку

Нажмите **«📋 Все станции»** или кнопку **«📋 Сводка по всем»**. Бот параллельно проверит все 11 станций и соберёт результаты в одном сообщении.

### Подключить Spotify

1. Нажмите **«🟢 Подключить Spotify»**.
2. Перейдите по ссылке, войдите в Spotify и разрешите чтение любимых треков.
3. Если после подтверждения открылась недоступная страница `127.0.0.1`, скопируйте полный адрес из строки браузера и отправьте его боту.
4. Бот завершит подключение и удалит сообщение с одноразовым кодом.

Авторизация сохраняется между перезапусками. Когда временный токен истекает, бот обновляет его автоматически.

### Посмотреть последние лайки

Кнопка **«💚 Последние лайки»** показывает 10 композиций, которые пользователь добавил в любимые последними.

### Получать уведомления

Бот раз в минуту проверяет эфир всех станций и сравнивает композиции со всей библиотекой любимых треков Spotify, а не только с последними десятью.

Список Spotify кешируется на 10 минут. Для сравнения бот:

- игнорирует регистр, лишние пробелы и знаки препинания;
- одинаково обрабатывает `ё/е` и `&/and`;
- убирает пометки `Radio Edit`, `Remix`, `Remastered` и похожие;
- допускает небольшие опечатки с помощью строгого нечёткого сравнения;
- не использует нечёткое сравнение для слишком коротких названий, чтобы избежать ложных совпадений.

Одно и то же совпадение не отправляется повторно при каждой проверке. История уведомлений сохраняется после перезапуска.

## Откуда берутся данные

Для станций используются разные источники: официальные страницы, JSON-метаданные, HLS-метаданные и ICY-данные эфирных потоков. Если основной источник станции временно недоступен, бот пытается получить название из альтернативного потока.

Такой подход нужен потому, что единого надёжного каталога текущих песен для всех радиостанций не существует.

## Журнал эфира

История композиций записывается в `logs/airplay.log` в кодировке UTF-8:

```text
2026-08-07 19:31:11 Европа Плюс — The Second Voice - LET ME BE
2026-08-07 19:31:11 Энерджи — Alok & Sigala feat. Ellie Goulding - All By Myself
```

Новый трек записывается сразу. Одинаковая композиция одной станции не дублируется чаще одного раза за три минуты. Файл ограничен 5 МБ, после чего создаются архивные копии.

## Минимальный запуск

Требуется Python 3.11 или новее.

```powershell
python -m venv .venv
.venv\Scripts\pip.exe install -r requirements.txt
Copy-Item .env.example .env
.venv\Scripts\python.exe -m src.bot
```

Перед запуском заполните `BOT_TOKEN` и настройки Spotify в `.env`. Файл `.env`, база `data/spotify.sqlite3` и папка `logs/` исключены из Git.

Проверка проекта:

```powershell
.venv\Scripts\python.exe -m unittest discover -s tests -v
.venv\Scripts\ruff.exe format .
.venv\Scripts\ruff.exe check .
```
